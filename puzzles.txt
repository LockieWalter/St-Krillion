#  HOW TO ADD A DAY
#    1. Put the date on its own line, written YYYY-MM-DD.
#    2. Start each prompt with "Q:".
#    3. Under each prompt, list the accepted answers by rarity.
#       Points are metres climbed:
#         wine:     Wine Glass, 10 m. The obvious ones everyone says.

#         piano:    Piano, 50 m
#         chalice:  Chalice, 75 m
#         swords:   Crossed Swords, 100 m. The ones nobody will think of.
#       (1: to 5: work too.) Separate answers with commas. Put
#       alternate spellings after a slash:
#         piano: Freshwater / Freshie, Shelly Beach / Shelly
#    4. Anything that isn't listed scores nothing, so list generously.
#
#  Capitals, punctuation, "the", plurals, typos and shortenings are
#  forgiven automatically: "vet" counts as Veterinary Medicine, "mech
#  eng" as Mechanical Engineering, "dining" as Dining Hall. A guess that
#  could be several answers gets the most common one. You don't need to
#  list those variations, but do add nicknames (Sals, Jim's, ABC).
#

#    saving anything. The page lists any lines it couldn't read, and

#    No. 1, …/?day=2 for No. 2). Post that in the group on the day.
